# Kettle Korn Factory — static website

Open `index.html` in a browser or deploy the folder to any static host.

## Supplied assets
- `assets/kettle-korn-logo.svg` — supplied source logo
- `assets/kettle-korn-logo-cropped.png` — tightened transparent crop used in the header
- `assets/kettle-korn-trailer.png` — supplied trailer photo
- `assets/favicon.png` — favicon generated from the supplied logo

## Before publishing
- Replace the placeholder phone number `(208) 555-0147` in `index.html` with the real business number.
- Replace the sample event dates/locations with confirmed appearances.
- The stylesheet currently loads DM Sans and Playfair Display from Google Fonts; remove the `@import` if you want a completely offline site.
